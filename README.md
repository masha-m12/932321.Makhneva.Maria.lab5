## Лабораторная работа №5. DOM и взаимодействие с элементами страницы.  

### Описание работы  
 
Дополнена HTML-страница «О себе» из предыдущих лабораторных работ с помощью скрипта, написанного на JavaScript – **dom.js**. Скрипт реализует интерактивное управление блоком «Хобби»: позволяет добавлять новые карточки, переключать вид списка, менять тему оформления и скрывать секцию. Все изменения состояния сохраняются в памяти браузера.  

### Реализация  

**Поиск элементов:** `getElementById`, `querySelector`, `querySelectorAll`.  
**Добавление хобби:** кнопка «Добавить хобби» запрашивает название и описание, после чего создаёт новую карточку с иконкой.  
**Переключение вида:** кнопка переключает `view-grid` и `view-list`(переключение между сеткой и списком) + возвращение к исходному варианту.  
**Переключение темы:** кнопка переключает на тёмную тему и меняет текст(«Тёмная тема»/«Светлая тема»).  
**Скрытие/показ карточек хобби:** кнопка добавляет или убирает `hidden` у секции с хобби.  
**Сохранение в localStorage:** сохраняются добавленные хобби, выбранная тема и скрытие/показ карточек хобби.
